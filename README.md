Untitled platformer game


Untitled platformer game is a simple platformer game I made on godot. It's my first godot game, so I had to watch a few tutorials to learn the basics.



How to play:

Go to: https://insertnewusernamehere.itch.io/untitled-platformer-game
and enjoy the game!


Controls:

Arrow Keys/ WASD - Move

Space - Jump



Goal:

Collect coins and reach the end!
